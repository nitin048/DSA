## 📖 Core Concepts

- **Big O:** Upper bound representing worst-case runtime complexity.
- **Complexity Orders:** O(1) &lt; O(log N) &lt; O(N) &lt; O(N log N) &lt; O(N^2) &lt; O(2^N).
- **Space Complexity:** Focuses on auxiliary memory allocations excluding original inputs.

## 💻 C++ Implementation Reference

```cpp
// Linear loop: O(N) time complexity
for (int i = 0; i < N; ++i) { ... }

// Logarithmic step: O(log N) time
for (int i = 1; i < N; i *= 2) { ... }
```
